Unit 1–2 · 探索单变量与双变量数据
五年均有出现 · Q1和Q2高频 · 图表读图是必考基础
分布描述框架（histogram/dotplot/boxplot）必考
  • 必须包含：① context（变量名）② shape ③ center（用median） ④ spread（IQR或range） ⑤ unusual features（outlier或gap）
  • center必须用approximate语言："approximately 11.5" 或 "between 11 and 12"，不能说"the mean IS 11.5"（确定性语言扣分）
  • boxplot不能说shape为"normal"或"unimodal"——boxplot无法判断，说了反而扣分
  • shape可以说：skewed left/right，approximately symmetric；outlier只说"potential outlier"不说"is an outlier"
❌ 常见错误："The mean of the distribution is 7.5" → 改为 "The center of the distribution is approximately 7 to 8"
比较两组分布（必须直接比较）必考
  • 必须用comparative language："greater than / less than / similar to"，单独列出数据不算比较
  • 比较center → 用median（不用mean，除非题目已给mean）
  • 比较spread → 优先IQR，也可range，说两个更好
  • 有outlier → 必须提，说哪组有/哪组没有
  • context → 同时提两组标签 + 变量名，缺一扣分
模板："The distribution of [Y] for [Group A] has a higher center than [Group B]. The median for Group A (X) is greater than the median for Group B (Y)..."
均值vs中位数的关系 理解题
  • 右偏/右侧outlier → mean > median（mean被拉向右尾）
  • 左偏/左侧outlier → mean < median
  • 必须解释机制：mean is not resistant to outliers/skewness，被极端值拉动
  • 只说"skewed"不指方向 → 不得分；必须说"skewed to the right"
Segmented bar / Mosaic plot读图 高频陷阱22/24年
  • 比例（proportion）：看各bar中对应颜色高度，与总量无关
  • 数量（count/number）：必须 n × proportion 才能判断，不能只看比例
  • Mosaic plot：列宽代表总量，列内高度代表比例 → 两者同时可见
  • Simpson's Paradox（22年Q6）：整体看A更好，但分层后B更好 → 因为两组的subgroup构成不同
❌ 22年最常见错误：以为proportion高 = number多 → 必须乘以各组total才能比数量
LSRL · slope/r²/residual解释 双变量22/23年
  • slope解释：x每增加1单位，predicted y增加/减少b单位（必须有"predicted"或"estimated"）
  • r²解释：约r²%的y的变异可由x与y的线性关系解释（必须说y的变异，不是"data的变异"）
  • residual = actual − predicted；正residual → 点在线上方 → underestimate；负residual → 点在线下方 → overestimate
  • 必须有单位：slope说"grams per millimeter"，r²不需要单位
❌ r²错误写法："81.9% of the variability in the data" 或 "in the predicted mass" → 必须是 "in the mass (y变量)"
Outlier两种判断方法 计算题21/24年
  • Method A（1.5×IQR rule）：low fence = Q1−1.5×IQR；high fence = Q3+1.5×IQR；超出范围为outlier
  • Method B（2 SD rule）：mean±2×SD区间外为outlier
  • 右偏分布：Method A比Method B识别出更多outlier，因为mean和SD被右尾拉大，使得Method B的上界更远
  • 必须代入具体数字验证，不能只说"使用rule"
Low fence = Q1 − 1.5×IQR | High fence = Q3 + 1.5×IQR
散点图描述（5要素）双变量21/22/23年
  • ① direction（positive/negative） ② form（linear/nonlinear） ③ strength（strong/moderate/weak） ④ unusual features（outlier/influential point） ⑤ context（变量名）
  • 缺context直接降P；缺direction或strength也降P
  • 2021年Q6评分标准明确：只说"strong"不说方向不得分；只说"linear"不说strength不得分
Unit 3 · 抽样、实验设计与推广
五年均有出现 · Q2和Q3高频 · 因果推断是核心概念
随机分配方法描述（Completely Randomized Design）必考
  • 必须说：① 给实验单元编号（01–60） ② 随机过程（random number generator / 纸条+混合抽取）③ without replacement ④ 分配结果（谁分到哪个treatment）
  • 纸条法：必须说"同等大小""充分混合（mix well）""不放回抽取"，缺一降P
  • 随机数法：必须标明范围（如01–70），忽略超出范围的数，不放回
  • Matched-pairs设计：每对内部随机决定谁先用treatment（掷硬币/随机数），必须说清楚两种结果各对应什么处理
❌ 22年常见错误："flip a coin; if heads, give twin A the drug" → 没说if tails是什么 → 不得E
分层抽样（Stratified Random Sampling）实施必考25年Q2
  • 必须说：① strata如何划分（如按row A–E）② 每个stratum内随机选取的方法 ③ 各stratum独立选取 ④ 每个stratum选出规定数量
  • 25年评分标准：4个components缺任何一个都降P
  • 不能把所有region混在一起再选 → 那不是stratified，是SRS
因果推断与推广的核心概念 必考
  • Random assignment → 建立因果关系（causal inference）
  • Random sampling → 推广到总体（generalization）
  • 两者独立：有实验没random sampling → 不能推广；有random sampling没random assignment → 不能建立因果
  • 21年Q2(c)：observational study → 只有association，不能说causes → 需指出confounding variable的存在
记忆：Assignment → Causation；Sampling → Generalization。两个"A→C，S→G"。
Matched-pairs设计的优势 概念题22年Q2
  • 正确答法：配对设计让我们更容易检测到治疗效果（reduces variability in the estimate of the drug effect / makes it easier to find convincing evidence）
  • 必须用comparative language（"easier than"/"better than CRD"）+ context
  • 以下说法看起来对但不得分：reduces bias / accounts for variability / controls confounding（两种设计都能做到）
  • 以下也不得分：只描述配对的setup，没说出优势
Confounding variable的完整论证 高频21/22/24年
  • 必须同时说三件事：① confounding variable与response variable有关联 ② confounding variable与explanatory variable有关联 ③ 因此无法确定是explanatory variable导致了response variable的变化
  • 21年评分标准：只说"存在confounding variable"但没说两个关联 → 只得P
  • 偏差（bias）的方向必须说明（under/overestimate），不能只说"有偏差"
模板："[Confounding variable] is associated with [X] and also associated with [Y], so it is impossible to determine whether [X] caused the change in [Y]."
观察研究vs实验 + 偏差类型 概念题
  • Observational study：不干预，只记录 → 只能说association，不能说causes
  • Experiment：随机分配treatment → 可以建立因果（if conditions met）
  • Convenience sample：非随机，likely biased；Voluntary response：自愿，倾向极端意见
  • Response bias：自我报告可能系统性低报/高报（如21年Q2日记vs activity tracker）
Unit 4–6 · 概率、随机变量与分布
五年均有出现 · calculator notation规范是失分重灾区
Calculator Notation规范（失分第一名）必须背
  • binomial：必须标参数名AND boundary值：1-binomcdf(n=20, p=0.10, upper bound=3) ✅
  • 1-binomcdf(20, 0.10, 3) ❌ → n和p没标，boundary没标，两个component都不得分
  • 1-binomcdf(n=20, p=0.10, 3) ❌ → boundary没标，不得分
  • normal：normalcdf(lower=296, upper=304, mean=300, sd=5) ✅；参数必须全部标明
  • 21年评分标准列出了全部合格/不合格写法，规则统一：n、p、boundary必须全部标参数名
Binomial Distribution · 完整定义RV 必考
  • 定义RV必须包含："the number of [successes] in [n trials / one hour / a 52-week year]"
  • 说明分布：X ~ B(n, p) 或 "binomial with n=___ and p=___"
  • 四个条件：fixed n / independent / binary outcome / constant p
  • 期望值计算必须展示：E(X) = np = 52(0.005) = 0.26，不能只写答案
μ = np | σ = √(np(1−p)) | P(X≥k) = 1 − binomcdf(n=_, p=_, upper bound=k−1)
期望值解释（三要素缺一不可）必考
  • ① 长期重复（in the long run / if repeated many times / over many years）
  • ② 平均值（average / mean，不能说"will receive exactly"）
  • ③ context（变量名，如gift cards / bedrooms / cash prize）
  • 21/23/24/25年均考期望值解释，三年评分标准都要求三要素
模板："If [scenario] were repeated many times, the average [variable] would be approximately [E(X)] per [unit]."
Geometric Distribution 公式题24年Q4
  • 适用：重复独立试验，直到第一次成功，记录总试验次数x（x从1开始）
  • P(X=x) = (1−p)^(x−1) · p
  • μ = 1/p；σ = √(1−p)/p
  • vs binomial：几何分布n不固定，直到成功为止；二项分布n固定
Geometric: μ = 1/p | σ = √(1−p)/p | P(X=x) = (1−p)^(x−1)·p
正态分布概率计算 必考
  • 必须展示：① 说明使用正态分布 + 均值和标准差参数 ② 标明事件范围（boundary + direction） ③ 正确概率
  • z-score = (x−μ)/σ，分子不能颠倒（颠倒只得P）
  • 抽样分布：σ_x̄ = σ/√n，必须展示除以√n的过程
  • 线性变换：E(aX+b) = a·E(X)+b；Var(aX+b) = a²·Var(X)（23年Q3(d)考了换算货币）
σ_x̄ = σ/√n | z = (x−μ)/σ | E(aX+b) = aE(X)+b
条件概率 + Two-way Table 计算题21/24年
  • Joint probability：P(A and B) = cell count / grand total
  • Conditional probability：P(A|B) = P(A∩B)/P(B) = cell count / row or column total
  • 分母是"given"对应的那行/那列的total，不是grand total
P(A|B) = P(A∩B)/P(B) = cell / row total
Unit 7–9 · 推断核心（Inference）
五年均有Q4 = 完整推断题 · 三段式框架不能错
假设检验三段式 · Section 1 · Hypotheses + Test Name 必考
  • 检验名称必须完整：one-proportion z-test（不能只说one-sample z-test）；matched pairs t-test for a mean difference；two-proportion z-test
  • H₀ and Hₐ必须：① 用population parameter（p, μ, μd）② 有正确等式/不等式 ③ context包含总体描述+sampling units+response variable
  • 用p̂代替p写hypothesis → component 2不得分（除非明确定义p̂为population proportion）
Context三要素："the true proportion of [sampling units] at [location] who [response variable]"
假设检验三段式 · Section 2 · Conditions 必考
  • Independence条件：① random sample/assignment（写"SRS-check"可以，但不能写"random-check"）② n ≤ 10%N（写出具体计算：130 ≤ 0.10×2000）
  • Normality · proportion：np₀ ≥ 10 且 n(1−p₀) ≥ 10，用p₀不用p̂，必须代入计算值
  • Normality · mean：n ≥ 30（CLT）或分布no strongly skewed/no outliers（n<30时）
  • Paired t-test：independence来自random assignment，不是random sample
❌ 常见错误：proportion条件用p̂而非p₀；independence只写"random"不写"sample"；10%条件忘记写
假设检验三段式 · Section 3 · Conclusion 必考
  • 必须包含：① p-value与α的明确比较（"p-value of 0.023 < α = 0.05"）② reject/fail to reject H₀ ③ context结论（population层面）④ nondefinitive语言
  • p-value comparison可以用critical value替代（如z=1.99 > 1.645）
  • 结论必须说population，不能说sample（"the sample proportion shows..." → 扣分）
模板："Because the p-value (0.023) < α (0.05), we reject H₀. There is convincing statistical evidence that [Hₐ in context with population language]."
❌ 语言禁区：accept H₀ / proves / confirms / there is no evidence / the data shows（这几个直接扣分）
置信区间 · 构建 + 解释 + 联动检验 必考22/25年
  • 解释必须说：We are C% confident that the true [parameter] is between [L] and [U]
  • 不能说"95% probability that population proportion is in the interval"（population parameter不是随机变量）
  • CI联动检验：null value不在CI内 → reject H₀；在CI内 → fail to reject H₀
  • 97% CI ↔ α=0.03双侧检验；95% CI ↔ α=0.05双侧检验
  • Conditions：proportion用p̂计算SE（CI）；hypothesis test用p₀计算SE（z-test）
CI: p̂ ± z* × √(p̂(1−p̂)/n) | z-test: z = (p̂−p₀)/√(p₀(1−p₀)/n)
Paired t-test vs Two-sample t-test的选择 必须能区分23/25年
  • Paired：同一被试两次测量，或有意义地自然配对（如双胞胎/同一条件下的before-after）
  • Two-sample：两组不同被试，random assignment分到各组，没有自然配对
  • 23年Q4：omega-3 vs placebo，同一患者两周分别接受两种处理 → Paired（crossover design）
  • 25年Q6：100名儿童随机分到9am和3pm两组 → Two-sample（独立，无配对）
  • 判断关键：是否同一个对象接受两次处理，或是否有meaningful pairing
Type I / Type II 错误 + Consequence 概念题
  • Type I：H₀为真，却reject → 错误地认为[Hₐ]成立
  • Type II：H₀为假，却fail to reject → 错误地认为没有证据支持[Hₐ]
  • 21年Q4(b)：fail to reject H₀后 → 可能犯Type II error → consequence：没有推出coupon，但实际上coupon有效
  • 必须说consequence（现实影响），不能只定义错误类型
Type I模板："Concluding that [Hₐ] when in fact [H₀] is true, so [consequence]."
Simulation估算p-value 非公式法22年Q5
  • 步骤：① 在模拟dotplot上数出"大于等于observed statistic"的点数 ② 除以总试验次数 ③ 与α比较 ④ 给出结论in context
  • 22年：3/120 = 0.025 < 0.05 → convincing evidence
  • 必须说明p-value是"假设H₀成立时，得到这么极端结果的概率"
Cohen's d Effect Size 新考点25年Q6
  • d = |x̄₁−x̄₂| / sp，等组时sp = √((s₁²+s₂²)/2)
  • 解读：d<0.20 = not meaningful；0.20–0.80 = somewhat meaningful；≥0.80 = very meaningful
  • 统计显著（small p-value）≠ 实际重要（large d）；大样本下小差异也可显著
  • sd增大 → sp增大 → d减小 → practical importance减小
sp = √((s₁²+s₂²)/2) | d = |x̄₁−x̄₂|/sp
Chi-square · 专项速查
两种chi-square必须区分 · H₀写法是高频失分点
两种Chi-square检验的区分 必须能区分
Chi-square for Homogeneity
  • 多个独立随机样本（从不同总体各取一个）
  • 比较同一变量在各总体的分布是否相同
  • 21年Q5：Baltimore/Detroit/San Diego三个独立样本
  • H₀：The proportion of [Y] is the same across [all groups]
Chi-square for Association
  • 一个随机样本，两个分类变量
  • 检验两个变量之间是否有关联
  • 24年Q5：500名collectors，month vs card type
  • H₀：There is no association between [X] and [Y] in the population
Chi-square H₀的正确写法 失分陷阱
  • Homogeneity H₀："The proportion of [variable] is the same across [all groups/cities]" ✅
  • Association H₀："There is no association between [X] and [Y] in the population" ✅
  • Hₐ不能写成单方向（"Group A has higher proportion than Group B"）→ 必须说"at least one group differs"或"there is an association"
  • H₀不能写"independent"（要写"no association"）
  • H₀ / Hₐ不能引用sample proportion → 必须是population层面
❌ 错误：H₀: p₁ = p₂ = p₃（用样本notation）→ 必须用words说明是population proportion相等
Chi-square计算要点 计算
  • df = (rows−1)(columns−1)
  • expected count = (row total × column total) / grand total
  • conditions：所有expected count ≥ 5（不是observed count）
  • χ² = Σ(observed−expected)²/expected
  • p-value = P(χ² > calculated value)，查chi-square table用df
E = (row total × col total) / n | df = (r−1)(c−1)
回归推断 · Slope的t-test专项
23年Q5完整考过 · 历年也有slope/r²解释 · 必须掌握
Slope推断 · t-test for slope 23年Q5完整考
  • H₀: β = [value]；Hₐ: β ≠ [value]（或 >/<）；β是population slope
  • df = n − 2（不是n−1）
  • 双侧检验p-value = 2 × 单侧查表值
  • 23年：t=3.408，df=28，单侧p<0.001，双侧p=0.002
  • 结论：evidence that population slope is different from [null value]（不能说"equals"或"is exactly"）
df = n−2 | two-sided p = 2 × one-sided p
LSRL · slope/r²/residual解释精要 高频
  • slope必须说：predicted y每增加b单位，per one-unit increase in x + 单位
  • r²必须说：约r²%的y变量的变异可由x与y的线性关系解释（不能说data/predicted y/both variables）
  • residual = actual − predicted；点在线上方 → 正residual → 线underestimate；点在线下方 → 负residual → 线overestimate
  • 描述散点图关系时：direction + form + strength + unusual features + context，缺context降P
语言禁区 · 写了必扣分
来自五年评分标准 · 每一条都有明确扣分记录
推断结论语言禁区 直接从E降P或P降I
  • ❌ "accept H₀" → ✅ "fail to reject H₀"
  • ❌ "proves / confirms / shows" → ✅ "provides convincing statistical evidence"
  • ❌ "there is no evidence" → ✅ "there is not convincing statistical evidence"
  • ❌ "the data shows [population]..." → ✅ 结论必须是关于population parameter
  • ❌ "there is a 95% chance the population proportion is between..." → ✅ "we are 95% confident that..."（population parameter不是随机变量）
  • ❌ p-value解释为"H₀为真的概率" → ✅ "the probability of getting a result this extreme assuming H₀ is true"
数据分析语言禁区 直接降分
  • ❌ boxplot说"normal" / "unimodal" / "bimodal" → boxplot看不出，说了会扣分
  • ❌ center只列数值不比较 → ✅ 必须用"greater than/less than"
  • ❌ slope说"y increases by b" → ✅ 必须说"predicted y increases by b"
  • ❌ r²说"variation in the data" → ✅ 必须说"variation in [y variable]"
  • ❌ center用确定性语言"the median is 7.5" → ✅ "approximately 7.5" 或 "between 7 and 8"
Context缺失（每题都要）系统性失分
  • 所有推断结论：population描述 + sampling units + response variable，三者缺一降P
  • 期望值解释：必须有context（gift card / bedroom / cash prize）
  • 分布比较：必须同时有两组的标签 + 变量名
  • slope解释：必须有两个变量的单位（grams per millimeter，不能省略单位）
  • 推断结论：conclusion必须和Hₐ方向一致；如果是"fail to reject"，结论是"not convincing evidence that [Hₐ]"
Calculator使用禁区 计算题
  • ❌ 只写calculator输出答案，没有支持公式或过程 → 不得show work分
  • ❌ binomcdf(20, 0.10, 3) → 参数名全缺 → 不得分
  • ❌ normalcdf(296, 304, 300, 5) → 参数名全缺 → 不得分
  • ❌ 期望值用calculator 1-VAR STATS → 不得分（必须手写Σx·P(x)）
  • ✅ 公式/notation + 代值 → 即使计算结果出错也得方法分

Boxplot比较两组分布 25年Q1 / 高频
满分写法
Country A 的gas mileage center较低，因为median约18 mpg，小于Country B的median约32 mpg；Country A的range略大，但IQR较小；Country A有一个高端outlier，Country B没有明显outlier。为什么得E：直接比较center/spread/outlier，并且有两组标签和变量context。
半对写法
Country A median is 18, IQR is 8. Country B median is 32, IQR is 12.为什么只能P：列了数值，但没有用greater/less/directly compare的语言；评分标准要求“直接比较”。
错误写法
Country A is normal and Country B is unimodal. The mean of A is 18.为什么不得E：boxplot不能判断normal/unimodal；用mean描述boxplot center也不合适。
考场句型：The distribution of [variable] for [group 1] has a lower/higher center than [group 2] because the median is...
均值、中位数、outlier关系 25年Q1
满分写法
The mean is expected to be greater than 18 mpg because the distribution is right-skewed / has a high outlier, which pulls the nonresistant mean above the median of 18 mpg.为什么得E：说清mean方向、median数值、右偏/高端outlier如何拉动mean。
半对写法
The mean is greater because the distribution is skewed.为什么只能P：方向说对，但“skewed”没说right/left，也没解释为什么mean被拉高。
错误写法
The mean is 18 because the median is 18.为什么错：mean和median不是同一个量；有右侧outlier时mean通常大于median。
Stratified Random Sample实施 25年Q2
满分写法
把每一行作为一个stratum。分别在A行1–5、B行6–10、C行11–15、D行16–20、E行21–25中用RNG随机选1个region；每行独立进行，最后检查被选中region里的所有cabbage plants。为什么得E：strata、等可能随机、各stratum独立、每层选1个都完整。
半对写法
Use a random number generator to choose 5 regions from 1 to 25.为什么只能P/甚至I：有随机，但不能保证每一行选1个；没有真正执行stratified sampling。
错误写法
Choose the five regions closest to the river because aphids are more common there.为什么错：这是biased/convenience selection，不能估计整个field的proportion。
易错点：用纸条法必须说mix well/shuffle；用随机数法必须说明每一层的号码范围。
Probability中的独立性与replacement 25年Q3
满分写法
Because a song can be replayed, the selections are independent. P(both rock songs)=0.10×0.10=0.01.为什么得E：看懂“can be replayed”，所以不是without replacement。
半对写法
P(both)=100/1000 × 99/999 = 0.0099.为什么会丢分：这是without replacement的逻辑；题目允许replay，所以第二次概率仍是0.10。
错误写法
P(both)=0.10+0.10=0.20.为什么错：both/and要乘，不是加。
Binomial + Calculator Notation 21/25年高频
满分写法
Let X = number of rock songs played in one hour. X ~ Binomial(n=20, p=0.10). P(X ≥ 4)=1−binomcdf(n=20, p=0.10, upper bound=3)=0.133.为什么得E：RV定义、distribution、参数、boundary都清楚。
半对写法
1−binomcdf(20, 0.10, 3)=0.133.为什么容易丢show work：答案对，但calculator参数和boundary未标明，评分标准可能不给过程分。
错误写法
Use normalcdf because n=20 is large enough.为什么错：这里要求binomial模型；且np=2，不满足常规正态近似条件。
Hypothesis Test参数与条件 25年Q4 / 每年必考
满分写法
H0: p=0.22; Ha: p>0.22, where p is the true proportion of students at Karen's high school who use the app at least once per week. One-proportion z-test. Conditions: random sample of 130 students; 130≤10%(2000); 130(0.22)=28.6 and 130(0.78)=101.4 are at least 10.为什么得E：test name精确、parameter context完整、independence和large counts都用null值检查。
半对写法
H0: p̂=0.22; Ha: p̂>0.22. Random-check. 38 and 92 are both greater than 10.为什么只能P：p̂是样本统计量，不是parameter；random-check太含糊；比例检验条件最好用p0算expected counts。
错误写法
Use a one-sample t-test because the sample size is 130.为什么错：这是population proportion，应该用one-proportion z-test，不是t-test。
推断结论：非确定性 + population context 每年Q4/Q6
满分写法
Because the p-value 0.023 is less than α=0.05, reject H0. There is convincing statistical evidence that the true proportion of students at Karen's high school who use the app at least once per week is greater than 0.22.为什么得E：比较p-value和α，decision正确，结论按Ha方向写，并且是population。
半对写法
The sample proportion is greater than 0.22, so Karen is right.为什么只给很少分：结论变成sample；没有p-value/alpha；语言太确定。
错误写法
Accept Ha. This proves more students use the app.为什么错：不能accept alternative；proves是确定性语言，评分标准明确不接受。
CI联动检验 22/25年
满分写法
Because 2.9 is not contained in the 97% confidence interval, reject H0 at α=0.03. There is convincing evidence that the population mean number of bedrooms in newly built houses in 2024 is different from 2.9.为什么得E：把null value是否在CI内和双侧检验结论正确连接。
半对写法
I am 97% confident the mean is in the interval, so the sample mean is different from 2.9.为什么不够：结论对象必须是population mean，不是sample mean；还要明确null value不在interval。
错误写法
There is a 97% chance that μ is in the interval.为什么错：parameter不是随机变量；正确是“we are 97% confident”。
Statistical Significance vs Practical Importance 25年Q6
满分写法
p-value=0.002 gives statistical evidence of a difference in mean reading scores. Cohen's d≈0.63 describes practical importance, so the effect is somewhat meaningful in real life. If both standard deviations increase while the mean difference stays the same, Cohen's d decreases, so practical importance decreases.为什么得E：把p-value和effect size的功能分开，并解释denominator变大导致d变小。
半对写法
The p-value is small, so the result is very meaningful in real life.为什么会扣分：p-value说明statistical evidence，不直接说明实际意义大小。
错误写法
If standard deviations increase, Cohen's d increases because there is more variability.为什么错：Cohen's d的标准差在分母；分母变大，d变小。

Q6评分（Investigative Task）特殊规则
  • 每个part独立算：E=1分，P=0.5分，相加后取整（2.5分用holistic判断升/降）
  • 各part独立得分，不会的跳过，继续做后面的part
  • Q6通常4–5个part，全拿E = 4分；3E1P = 3.5分 → holistic可能到4
  • holistic分：看communication质量，答得清晰、逻辑严密的往上靠
从P到E · 只差这一步 提分关键
  • Conditions：写了"random"但没写"sample" → P；加上"sample" → E
  • Conclusion：有p-value比较但结论没context → P；加上population + variable → E
  • 分布描述：有shape/center/spread但没context → P；加上变量名 → E
  • Slope解释：有数值和方向但没"predicted" → P；加上predicted → E
  • 期望值：算对了但解释只说"average"没有long run → P；加上long run → E
  • 随机分配：说了随机过程但没说"without replacement" → P；加上 → E
时间分配与考场策略 实战
  • Q1–Q5：建议各13分钟（共65分钟）；Q6：留25分钟
  • 推断题（Q4）顺序：先写hypotheses → conditions → calculations → conclusion，不要跳
  • 不确定的calculation：先写公式和代值，答案写错也得方法分
  • Q6时间不够：先写能写的part，每part首先写出结论，再补justification
  • Holistic分：答案之间有2.5时，清晰的communication往上打；混乱的往下打
